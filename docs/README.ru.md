# UltraExplorer

### Ваши файлы. Одна масштабируемая карта.

Нативный файловый менеджер Windows, который показывает иерархию папок на
холсте. Видно структуру, можно приблизиться к нужной папке и вернуться к
общему виду.

[Скачать для Windows](https://github.com/So2K/UltraExplorer/releases/latest) ·
[Попробовать v1.3.0 beta](https://github.com/So2K/UltraExplorer/releases/tag/v1.3.0-beta.1) ·
[English](../README.md) · [Сборка из исходников](../BUILD.md)

![Демонстрационное рабочее пространство и его вложенные папки](media/overview.png)

[Версия GIF](media/overview.gif)

**v1.3.0-beta.1 доступна для тестирования:** просмотр по Space, быстрые текстовые
заметки, компактный плеер и 3D-просмотр. Архивы как папки, полка и кнопка копирования
пути включаются отдельно в Settings и изначально выключены. Сценарии проверки и
порядок отправки ошибок — в [инструкции для beta](BETA_TESTING.md).

У каждого диска свой корень. Папки и файлы расположены внутри родителей, а
открытие папки перемещает камеру внутрь неё. Адресная строка, боковая панель,
файловые операции и контекстное меню Windows остаются привычными.

## Одна папка, два представления

| Навигация | Проводник Windows | UltraExplorer |
| --- | --- | --- |
| Переход по иерархии | Вход в каталоги со сменой текущего представления папки. | Приближение к вложенным папкам на одной карте. |
| Ориентация | Цепочка пути, Назад/Вперёд и боковая панель. | Та же навигация по пути плюс окружающая структура папок. |
| Возврат к проекту | Закреплённые расположения в боковой панели. | Избранное, цветные Tags и визуальные отметки на холсте. |

![Слева настоящий Проводник в режиме Details, справа анимированный холст UltraExplorer с той же папкой](media/explorer-comparison.png)

[Версия GIF](media/explorer-comparison.gif)

Слева настоящий Проводник Windows в режиме Details, уже открытый в целевой

на время.

## Как это работает

Анимированные PNG с частотой 30 кадров/с записаны из работающего приложения
через Windows Graphics Capture, с CPU-рендерером и заранее прочитанным
демонстрационным пространством. Время кадров соответствует исходным отметкам
записи. Под каждым роликом есть ссылка на версию GIF.

### Приближение к глубокой папке

Двойной клик переносит внутрь папки. Отдаление снова показывает её соседей и
родителей. Можно сразу вставить путь в адресную строку.

Содержимое читается по мере появления на экране. Холодные папки и сетевые
пути зависят от скорости ответа файловой системы.

![Переход к глубоко вложенной папке и обратно](media/deep-zoom.png)

[Версия GIF](media/deep-zoom.gif)

### Поиск с переходом на карту

`Ctrl+F` ищет по дискам. Сначала показаны результаты в текущей папке и под ней.
Результат можно увидеть на карте; `Ctrl+Enter` открывает его в стандартной
программе.

Для индексированного поиска рекомендуется
[Everything](https://www.voidtools.com/): UltraExplorer обращается к запущенной
программе напрямую, дополнительная SDK DLL не нужна. Без Everything папки
обходятся в фоне, результаты поступают по мере обхода. Доступ к дискам и
состав индекса определяют, что поиск найдёт.

![Поиск файла и переход к его расположению](media/search.png)

[Версия GIF](media/search.gif)

В этой записи поиск обходит только демонстрационное рабочее пространство.

### Цветные папки как теги

Поменяйте цвет папки — она появится в **Tags** под **Network**. Можно найти её
по цвету в компактном списке или на самом холсте. Клик по тегу переносит к
папке.

ПКМ открывает **Change color** и **Unpin**. Unpin убирает цвет и строку из
Tags, сохраняя заметку. Работают `Shift+F10` и клавиша Menu. Цвета и заметки
привязаны к путям и общие для окон приложения.

![Переход между уже окрашенными папками через Tags](media/tags.png)

[Версия GIF](media/tags.gif)

### Два места одновременно

Разделите холст по горизонтали или вертикали. У каждой панели своя камера,
выделение, фильтр и история. Можно перетащить файл в папку другой панели,
скопировать выделение через `Shift+F5` или переместить через `Shift+F6`.

## Возможности

- **Вложенный холст:** папки внутри папок, каждый диск — отдельный корень.
  В Settings → View доступен и холст с деревом узлов.
- **Нативная отрисовка:** C#/.NET 10, WPF для оболочки и Direct3D 11 для
  вложенного холста; предусмотрен CPU-рендерер.
- **Файловые операции:** открыть, копировать, вырезать, вставить, переименовать,
  дублировать, удалить в корзину, показать свойства и перетащить.
- **Контекстное меню Windows:** действия установленных Shell-расширений.
  Для выделения из разных родительских папок используется меню приложения.
- **Выделение и сортировка:** рамка, Ctrl/Shift, общее выделение списка и
  холста; порядок по имени, дате, типу или размеру сохраняется для папки.
- **Визуальные ориентиры:** цвета, заметки, закрепления и маяки для отметок
  за пределами текущего кадра.
- **Фильтр и слои:** подсветка имён в прочитанных ветках без смены раскладки;
  можно скрыть файлы, значки, подробности и отметки.

Карта показывает **структуру каталогов**, а не занятое место. Соседние папки
одинакового размера на холсте: по площади ячейки нельзя судить об объёме данных.

## Что изменилось в v1.2.1

Потеряли выделенный файл после отдаления? Нажмите **`F`**: камера плавно
приблизится к его крупной карточке. Сортировка, обновление папки и изменение
размера окна не сбивают цель; выделение и история остаются прежними.

Ревью также усилило безопасность запуска скриптов, результаты переноса файлов,
переходы при закрытии окна, работу с обновлёнными узлами графа и обновление
программы без удаления посторонних файлов.
[Результаты ревью и точные границы проверок](REVIEW_v1.2.1.md).

## Что изменилось в v1.2.0

В выпуск включены все 18 сохранённых пакетов ревью и дополнительные
межмодульные исправления. Основной акцент — предсказуемые действия с файлами
и навигация:

- Безопаснее обработаны внешние перетаскивания и выделение после удаления папки другой программой.
- Окна папок восстанавливаются раньше; улучшены передача из Проводника и навигация стрелками.
- Tags и заметки общие для окон; камера следует за переименованием, фильтр учитывает изменения видимости.
- Усилены защита операций между панелями и работа с устаревшими строками; запросы блокируют только своё окно.
- Подготовка файловых команд выполняется в фоне, потоковые результаты поиска переиспользуют строки, визуальные ориентиры кешируются.

Название канала не означает, что закрыты все замечания ревью или пройдены
все проверки. Их фактический объём и оставшиеся сбои указаны в заметках.

## Быстрый старт

| Действие | Клавиши |
| --- | --- |
| Зум к указателю | `Ctrl+колесо` |
| Панорама | Средняя/правая кнопка с перетаскиванием, `Space+перетаскивание`, колесо / `Shift+колесо` |
| Войти в папку / открыть файл | Двойной клик |
| Вся карта / выделенный объект | `Shift+1` / `Shift+2` |
| Плавно приблизить выбранный файл или папку | `F` |
| Ввести путь | `Ctrl+L` или `Alt+D` |
| Поиск по дискам | `Ctrl+F` |
| Показать / открыть результат | `Enter` / `Ctrl+Enter` |
| Фильтр прочитанных имён | `Ctrl+Shift+F` |
| Разделить рядом / друг над другом | `Ctrl+\` / `Ctrl+Shift+\` |
| Переключить панель | `F6` |
| Копировать / переместить в другую панель | `Shift+F5` / `Shift+F6` |
| Настройки | `Ctrl+,` |

Обычные клавиши Проводника — `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `F2`, `Delete`,
`Alt+Left` и `Alt+Up` — тоже работают.

## Интеграция с Windows

UltraExplorer можно использовать отдельно. В Settings включаются обработка
открытия папок и поддерживаемых Open/Save/Select Folder диалогов. Для `Win+E`
есть самостоятельная настройка. В новой установке эти функции выключены.

Неподдерживаемые виртуальные расположения и диалоги остаются в Windows.
В файловом диалоге доступно **Use the Windows dialog this time**,
в настройках — **Restore and pause**.

Подробнее: [интеграция с Проводником](EXPLORER_REPLACEMENT.md),
[файловые диалоги](DIALOG_INTEGRATION.md), [API picker](../PICKER.md).

## Текущие ограничения

- **View all** работает. **View select** зарезервирован и выключен.
- Фильтр видит прочитанные ветки. Для ещё не посещённого пути используйте поиск.
- У очень больших папок листинг на холсте может быть ограничен; холст не является полным индексом диска.
- Интеграция Open/Save поддерживает не все приложения и пространства Shell.
- Windows Shell может отказать в рекурсивном дублировании папки со слишком длинным деревом назначения. Приложение сообщает понятную ошибку; сократите имена или переместите дерево ближе к корню диска.
- Холст дерева пересоздаёт объекты узлов при обновлении. Ссылка, возвращённая параллельным переходом, может устареть после обновления предка; её валидность точно в момент возврата ещё исследуется.
- GPU-отрисовка пока ждёт завершения работы на общем UI-потоке. Неблокирующий конвейер остаётся отдельной задачей рендерера.

## Сборка и участие

На Windows x64 с [.NET 10 SDK](https://dotnet.microsoft.com/download):

```powershell
git clone https://github.com/So2K/UltraExplorer.git
cd UltraExplorer
dotnet build UltraExplorer.sln -c Release
dotnet run --project src/UltraExplorer/UltraExplorer.csproj -c Release
```

[BUILD.md](../BUILD.md) описывает публикацию, smoke-проверки, GPU-проверки и
воспроизводимые замеры. [Ревью отрисовки](RENDERING_ZOOM_REVIEW.md) объясняет
устройство рендерера. Скорость зависит от оборудования, содержимого папок и
состояния кеша; записи показывают сценарии, а не измеряют производительность.

Полезны воспроизводимые ошибки, улучшения клавиатурной навигации и
доступности, документация и переводы. Для первого вклада выберите один
конкретный сценарий и опишите ожидаемое поведение.
[Задачи good first issue](https://github.com/So2K/UltraExplorer/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22good%20first%20issue%22)
или [новый issue](https://github.com/So2K/UltraExplorer/issues/new).

Приоритеты разработки: предсказуемые навигация и файловые операции,
проверка больших каталогов и отключённых путей, обратная связь поиска,
доступность цветных ориентиров. Механика **View select** должна быть
определена до реализации.

Если идея вам полезна, поставьте звезду и расскажите о сценарии, который
хотите решить. Конкретная обратная связь помогает выбрать следующий шаг.
